# Gestenlerner (Prototyp)

Lernprototyp mit 5 Übungstypen (Geste, Multiple Choice, Paare, Rechtschreibung, Raster). Details: `DATENMODELL.md`.

## Adressen
- Live (nur freigegebene Version, Branch `main`): https://tommyate.github.io/EasyVoc/
- Test (neue Änderungen, Branch `test`): https://tommyate.github.io/EasyVoc/test/

## Arbeitsweise
1. Neue Version kommt immer zuerst auf den Branch `test`.
2. Du prüfst sie unter `/test/`.
3. Gefällt sie dir: Auf GitHub "Pull requests" → "New pull request" (base: `main`, compare: `test`) → "Merge". Danach ist sie live.
4. Gefällt sie nicht: nichts tun. `main` bleibt unverändert.
